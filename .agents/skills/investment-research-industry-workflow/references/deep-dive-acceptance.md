# 深研验收与停止点

## V2 全部门禁

私人研究档案逐条记录 PASS / GAP / BLOCKED、证据入口、核验日期和影响。以下全部通过，且由 ChatGPT Final Writer 完成 synthesis/主 Wiki 收口和成熟度判定，才可标记 V2。Codex 只交付各 gate 的证据与缺口，不能以 Handoff 完成代替 V2：

1. **公开原始资料基线**：官方/原始来源覆盖行业需求、供给、技术、周期、capex与利润池，网页/原件可追溯，券商不替代 baseline。
2. **M0—M13 当前认知完整**：沿用既有 taxonomy，每项有判断与依据，真正不适用有理由；关键未知未被模板占位掩盖。
3. **全球代表公司完整财报验证**：名单由生态位/经营数据证明，最新完整年报及最新季度/半年材料、关键附注已读，两个验证链清楚；未披露与未研究分开。
4. **跨生态位/利润池比较**：经营期间/币种/集团分部口径明确，控制点、供给瓶颈、产能周期、客户议价和潜在反证有证据，不能只列公司简介。
5. **统一估值与预期**：共同价格时点、财年/FY1/FY2、GAAP/adjusted、收入/EPS预期、FCF/资本强度与必要稀释分析完成。市值/EV/FCF仅可靠可得时填写；可靠一致预期缺失允许留空，但必须证明检索、提供可核验的实际值/指引或条件估值及结论限制。若核心比较因缺失无法成立，仍是 GAP，不能靠填“未知”通过。
6. **下行与证伪**：至少一组行业适配下行情景，参数/公式/假设可复算，对不同生态位的敏感性有解释；每个核心判断有明确证伪和观察入口。
7. **主 Wiki 收口（Writer 责任）**：最终整页为当前有效认知，无过期成熟度、失效下一步、施工日志堆叠；公司层/来源链接可达。Codex 只报告现状和待处理项，不执行最终写作。
8. **过程进入独立档案**：历史正文与阶段变化、原件身份/hash核验、财报/估值底稿、缺口及 gate 记录独立保存并回读，不删除历史证据。

## 行业适配的覆盖检查

根据行业实际需求来源、供给结构、技术路线、产业控制点、产能周期和利润池确定基线边界与代表公司，不固化某个行业的产品清单或公司名单。同公司跨环节须核实分部披露，不能重复计需求。

根据行业真实传导选择至少一组可复算的行业适配压力情景，明确参数、依据、公式、受影响生态位及限制。具体行业覆盖检查与已发生的 Pilot 验证留在研究档案或历史验证文档，不作为通用 SOP 要求。

## 停止和交付

- `NOT_READY`：D0 不可用、目标未唯一确定，或关键证据/五页合同尚不足以可靠交接；报告缺失能力，不生成假档案。已授权独立工程仍完成。
- `READY_WITH_GAPS`：五页及 Writing Brief 已生成并回读，重要事实可追溯、未知/冲突/失败和影响明确；仍有 L0/估值/披露缺口但 Writer 能辨别已知与未知。保留真实 Wiki Maturity，L0 GAP 不使 V1.2 回退为 V1.1；V2 若受阻保持 BLOCKED。
- `READY_FOR_CHATGPT_SYNTHESIS`：证据合同完整、重要来源和 L0 核验闭合、无阻断交接的证据缺口，数据/情景可复算。仍需 Writer 审计、最终 synthesis 与 Wiki 成熟度判定；不等于 V2 通过、人工审核或 OS 准入。
- 普通 Codex 深研停在上述两个 READY 状态之一，交付父页/五子页、三条状态轴、V2/V3、原件数量/核验、覆盖及未决项，明确未执行最终 Wiki 写作。不自行标 V2/V3 或勾选待研究项。
- OS Promotion Gate：普通研究“未触发”。用户另行要求正式事实/决策/组合写入才转相应领域工作流并履行原合同确认；不自动将研究结论晋升。
- 工程交付与研究验收分别记录；静态 check、合成演练、工具可用、真实研究完成互不替代。最终按用户 Git 边界停止，不创建未经授权 PR/merge/部署。
