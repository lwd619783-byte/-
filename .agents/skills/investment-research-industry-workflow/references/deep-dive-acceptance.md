# 深研验收与停止点

## V2 全部门禁

私人研究档案逐条记录 PASS / GAP / BLOCKED、证据入口、核验日期和影响。以下全部通过才可标记 V2：

1. **公开原始资料基线**：官方/原始来源覆盖行业需求、供给、技术、周期、capex与利润池，网页/原件可追溯，券商不替代 baseline。
2. **M0—M13 当前认知完整**：沿用既有 taxonomy，每项有判断与依据，真正不适用有理由；关键未知未被模板占位掩盖。
3. **全球代表公司完整财报验证**：名单由生态位/经营数据证明，最新完整年报及最新季度/半年材料、关键附注已读，两个验证链清楚；未披露与未研究分开。
4. **跨生态位/利润池比较**：经营期间/币种/集团分部口径明确，控制点、供给瓶颈、产能周期、客户议价和潜在反证有证据，不能只列公司简介。
5. **统一估值与预期**：共同价格时点、财年/FY1/FY2、GAAP/adjusted、收入/EPS预期、FCF/资本强度与必要稀释分析完成。市值/EV/FCF仅可靠可得时填写；可靠一致预期缺失允许留空，但必须证明检索、提供可核验的实际值/指引或条件估值及结论限制。若核心比较因缺失无法成立，仍是 GAP，不能靠填“未知”通过。
6. **下行与证伪**：至少一组行业适配下行情景，参数/公式/假设可复算，对不同生态位的敏感性有解释；每个核心判断有明确证伪和观察入口。
7. **主 Wiki 收口**：整页回读为当前有效认知，无过期成熟度、失效下一步、施工日志堆叠；公司层/来源链接可达。
8. **过程进入独立档案**：历史正文与阶段变化、原件身份/hash核验、财报/估值底稿、缺口及 gate 记录独立保存并回读，不删除历史证据。

## 电力与数据中心 Pilot 的覆盖检查

行业基线至少覆盖全球电力/数据中心电力需求、输配电/变压器/开关设备、UPS/PDU/母线等供配电、液冷/热管理、燃机/备用/新增电源，以及供给瓶颈/产能周期/capex/利润池。

公司选择优先代表输配电/电气设备、数据中心电力、热管理/液冷、发电设备/燃机的不同控制点，通常5—8家，不预设名单；同公司跨环节须核实分部披露，不能重复计需求。压力情景可选择 AI/DC capex 放缓、变压器/开关供给恢复压价、液冷渗透不及预期、燃机扩产/交付变化、大客户压价/项目延期；场景设定必须符合研究得到的实际传导。

## 停止和交付

- D0 不可用：研究未开始，现有成熟度只有回读确认后才能报告；写明缺失能力和唯一需用户完成的动作，不生成假档案。
- 后续关键缺口：保留最后有证据支持的成熟度，不勾选待研究项，报告完成/未完成门禁；已授权独立工程仍可完成。
- V2 通过：主 Wiki 标 V2，研究方式转 V3；交付真实入口、原件数量/核验状态、来源/公司覆盖与残余不确定性。
- OS Promotion Gate：普通研究“未触发”。用户另行要求正式事实/决策/组合写入才转相应领域工作流并履行原合同确认；不自动将研究结论晋升。
- 工程交付与研究验收分别记录；静态 check、合成演练、工具可用、真实研究完成互不替代。最终按用户 Git 边界停止，不创建未经授权 PR/merge/部署。
