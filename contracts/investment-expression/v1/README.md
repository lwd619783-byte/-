# Investment Expression V1 — additive decision contract

R3 implementation contract / PENDING INDEPENDENT AUDIT. Existing Thesis, Claim, F2, Entity/Stock/Asset and Phase 1 permissions retain their authority and wire semantics.

Expression answers how to express an exact formal Thesis. No quantity, position, expected return, price target, numeric score, probability, allocation or trading instruction exists in this closed schema. A stable ID has a linear immutable revision chain and separate append-only explicit user confirmations. AI origin never changes. Drafts may have null Thesis/instrument; formal confirmation may not.

FormalThesisRef pins thesisId/revisionId/confirmationId and canonical original bytes. These are integrity tokens, never fallback authority. Every preview, confirmation, import and formal read resolves the original Thesis repository and checks structure/history/schema, exact original revision and user confirmation, availability by Expression asOf, and original Thesis → Claim → F2 support. The pinned Thesis must be the last recorded revision at/before Expression asOf (inclusive), including draft successors. Later successors retain historical validity and produce a current review notice; no automatic pin replacement. Confirmation also rejects any change to the referenced Thesis history since preview, requiring a fresh preview.

InstrumentRef refers to existing Stock/Entity/Asset owners using unique exact identity, type and market. Category includes Index, ETF, Fund, Equity (A/H/US/global) and CommodityProxy. A trusted in-process read port must resolve the whole ref exactly. No labels/tickers/aliases, automatic registry creation or guessed markets. Current runtime only wires real Stock identities. Other categories remain unresolved/empty until an existing owner read port is available. Frozen synthetic fixtures exercise ETF/Index/Equity without importing them into production. Scope is immutable and every load/write/import rejects a foreign scope, including synthetic drafts in real runtime.

Directness, correlation, liquidity, valuation, sensitivity and idiosyncratic risk are qualitative research_judgement or explicit unknown with an explanation; unknown role/context is allowed and visible. No immutable financial context adapter is introduced, so these fields cannot claim Provider Fact. Existing upstream partial/stale/conflict/unknown blockers are retained through Thesis/F2. Research Context uses the existing safe kind/title/URL contract and never participates in verification.

Local-first follows prepare → preview → confirm → commit with original object binding, exact saved-byte stale-base checking, append-only revisions/confirmations and no delete. JSON imports are append-only, reject conflicting IDs, require explicit confirmation, rerun authority and back up original bytes before writing. Observed corruption can be recovered with explicit confirmation and pre-recovery backup; unknown schema versions lock recovery. Canonical JSON drives integrity and deterministic export. Backups are portable data within the existing local trust boundary, not cryptographically authenticated attestations. LocalStorage has no cross-tab atomic CAS. Missing historical owners conservatively block future append/import without deleting history.
