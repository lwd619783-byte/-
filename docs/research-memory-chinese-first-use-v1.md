# 研究记忆：中文与首次使用 V1

普通用户以“资料、整理建议、文章、版本、来源”理解知识库。首屏固定提供：① 添加资料 → ② AI 整理 → ③ 审核建议 → ④ 进入知识库。一级入口为“原始资料 / AI 整理 / 待审核 / 我的知识库”；空库直接展示添加资料，多文件选择为主操作，粘贴为辅助操作。

Source、Extraction、Revision、Current、Reviewed、Backlinks、owner、wikiId 等技术字段不能作为普通页面的导航、状态或主操作。需要保留的 ID、摘要、时间原值与权限诊断收进“高级信息 / 审计详情”。资料标题应显示文件名，文章应显示中文标题，状态应显示“等待解析 / 文本已提取 / 解析失败，原件已保存 / 待审核 / 已审核”。PDF、Markdown、TXT、AI、ChatGPT、Obsidian 等格式或产品名称可以保留。

“AI 分析服务尚未连接”必须直接说明。没有 Provider 时不得演示自动生成假结果。发送给 ChatGPT 需要用户明确选择批次，已有文章默认不选；在发送前显示复制内容、24 小时访问期限和撤销含义。密钥只在页面内存使用。

混合解析批次必须可恢复：原批次内选择已解析资料，失败项禁选且注明原件保留；展示所有未发送文件，用户确认本次所选/未发送数量后才启用发送。不得静默跳过、重建原件或要求清空存储。重新打开页面需要重新选择和确认。撤销承诺覆盖本批此前全部暂存（含所选知识），即使本机已丢失暂存编号也能操作；重发需重新确认，不恢复旧暂存。

文章阅读优先完整正文；摘要、核心判断、产业/主题结构、近期变化、关键环节、风险与来源不能仅由机器原子替代。更新建议必须同时展示当前文章、完整新文章、逐节变化及引文。用户可以接受、修改后接受或拒绝；需要审核说明。手工新建文章置于“更多操作”。文章、版本演化、证据来源为三个阅读层次，保留完整历史。

资料保存、文字提取、AI 研究、人工审核和来源核验是不同事实，成功提示不能混用。错误用中文说明保存了什么、哪一步失败、可采取什么操作；内部错误码不作为主叙述。私有原件不因页面完整性需要而伪造。窄屏允许垂直滚动，禁止用横向裁切掩盖布局问题。

验收必须用空 profile、真实 IndexedDB、实际解析器和表单流程；三主题 neon/pro/light × 1536/1280/390/320，检查资料页、整理页、审核页、完整文章和模态框。Synthetic fixtures 只存在于测试，不成为用户初始化数据。
