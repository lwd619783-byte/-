# 三套皮肤与图表规范

## 1. 主题身份与存储

| 原方案 | 内部稳定标识 | 中文名称 | 默认 |
|---|---|---|---|
| A | pro | 深色专业 | 否 |
| B | light | 明亮简洁 | 否 |
| C | neon | 霓虹科技 | 首次访问默认 |

设计配置文件是 [design/theme_tokens.json](design/theme_tokens.json)，不是生产CSS或已安装主题包。主题选择位于全局顶栏的“外观”。首次访问默认C，有效已保存偏好优先；不在本轮新增自动跟随系统模式，避免用户选定霓虹后被隐式切换。

新增偏好应使用独立、有版本的UI设置键，不复用 Watchlist / Expectation / Local Core 的业务存储键。非法值回到默认C；读写失败允许当前会话使用并提示，不阻塞业务。跨标签页是否同步只作用于外观，不传播任何业务写入；本轮默认不额外增加同步监听能力。

`up/down` 只表示金融方向，本版固定红涨绿跌并保留正负号。`warning/error` 表示数据/操作状态，不借用涨跌判断。`accent/secondary` 表示交互和普通图表系列，不表示投资评级。价格本身原则上中性，涨跌幅单独着色。

霓虹面板采用极轻的深蓝渐变，最亮色阶为 `#0C1E32`；普通边界是装饰线，关键可操作控件另用 `control` 色保证识别。控件状态不能只靠弱边框。选中/焦点有明确底色、边界和文字；正文不发光。

本包已按WCAG相对亮度公式检查142组指定不透明颜色对，包括正文/辅助/语义色、控件轮廓、主按钮文字和霓虹渐变最亮端。结果见 [checks/contrast.json](checks/contrast.json)。这只证明定义中的配色对，不能替代浏览器对透明叠加、字体、禁用态、缩放和真实交互的检查。[W01](09-source-register.md#w01wcag-22-文字对比与可读性)[W02](09-source-register.md#w02非文字对比)

## 3. 共享尺寸

| 项目 | V1 设计值 |
|---|---|
| 桌面基准画板 | 1600 × 1000，PNG按2倍输出 |
| 主导航 | 208px；内容起点240px；页面右边距24px |
| 顶栏 | 72px；常规内容间距20px |
| 圆角 | 普通面板10px、控件6px、标签5px |
| 正文 | 14px；长文14–15px / 24–28px |
| 表格 | 13px；表头/辅助12px；常规行44–56px |
| 操作目标 | 桌面按钮36–40px；触屏目标至少44px（项目设计目标） |
| 数字 | 主要KPI28–36px，tabular数字；不逐位跳动 |
| 图表 | 主图约280–380px；小图约180–220px；窄屏不压到不可读 |
| 动效 | 交互150–220ms；减少动态效果时关闭非必要过渡 |

44px为本项目触屏设计目标，不把它误写成WCAG 2.2 AA统一最低值；AA的2.5.8存在24 CSS px与例外规定。[W03](09-source-register.md#w03目标尺寸)

正文使用已有系统中文无衬线栈；设计稿用可用CJK字形渲染，部署由Codex检查系统字体差异。不能为了皮肤分别换一套字号或导致中文换行不同。仅装饰材质改变，不改变几何。

## 4. 图表目录与准入

| ID | 研究问题 | 默认图形 | 数据前提 / 禁止越界 |
|---|---|---|---|
| C01 | 已选公司价格变化 | 收盘价折线与末点 | 已有priceHistory；标时点/币种；没有OHLC不画K线 |
| C02 | 经营随报告期变化 | 分期柱形/小多图 | 正式财务可比字段；年度/单季/累计分开 |
| C03 | 研究池分布 | 横向数量条 | 说明池内范围；不称行业景气或全市场排名 |
| C04 | 预期是否匹配实际 | 点值/区间线+实际参考线 | 使用现有比较结果；来源类别与资格可見 |
| C05 | 证据如何演进 | 事件/修订时间线 | 原始时间精度和并列不确定性保留 |
| C06 | 同行之间比较 | 表格优先，必要时条图 | 指标、币种、期间、样本范围同口径 |
| C07 | 产业链关系 | 分层关系图 | 连接只表关系；不暗示收入权重或资金流 |
| C08 | 宏观历史观测 | 条件式时间序列 | 当前未接入序列则显示不可用；本轮不新增Provider |
| C09 | 数据质量 | 状态数量/明细列表 | 分母严格可解释；不生成置信概率或“完整度68%” |

常规图表继续使用现有Recharts；本轮不默认引入ECharts、TradingView、TanStack或大型UI框架，也不捆绑React/Tailwind升级。所需SVG原语是现有图表/组件范围内的表达，不提供新的财务计算引擎。[S15](09-source-register.md#s15依赖版本)

## 5. 坐标、单位与颜色

折线不跨缺失点补线，不把一个快照生成历史；不以视觉平滑制造转折。数量/金额比较条形图原则上从0起；价格线允许可读范围但坐标必须可见。不同单位用分面，不默认双轴。百分比与百分点明确区分；累计同比不可混为单季增速。

系列标识稳定，切皮肤时系列名称/颜色语义/图例顺序不变。普通多系列优先accent、secondary和另一条可区分系列，超过约4条默认改为筛选或小多图。颜色之外用标签、线型与点型。图表有效线条和必要图形对背景目标至少3:1；正文仍按正常字号4.5:1目标检查。[W01](09-source-register.md#w01wcag-22-文字对比与可读性)[W02](09-source-register.md#w02非文字对比)

饼图只在真实可加总、同口径且已实现的部分/整体关系成立时采用。本轮不增加证据置信饼图、主观雷达评分或装饰仪表盘。

## 6. 交互细节

悬浮提示含指标、值、单位、观察期/价格时点和数据限制，不把“生成于”显示成“发布于”。仅日期来源不能捏造时分秒。用户可通过键盘/触控获得同等信息；每张主要图提供原始数据表入口与简短文字摘要。

时间区间选择只列真实可支持范围，60日资料不显示可点的十年范围。切区间不改变用户研究记录。图例隐藏某系列属于展示状态，不删除底层观测或数据质量说明。

极端负值、大量级、零值、空集、部分失败、单点与长标签在验收夹具中独立覆盖。设计图中的数值不能复制进真实数据分支。
