## 4. 新增而非仅换皮的事项

N01主题选择与独立偏好；N02统一首页外壳；N03快速预览/完整研究分离；N04五标签与可恢复导航；N05复杂页基础/高级筛选收纳；N06窄屏主从转换；N07共享图表/提示框主题。全部属于前端增量，按D1–D5实现，不以“纯CSS”名义省略测试。

## 5. 明确不做

市场温度正式上线、全A股聚合准入、自动机构一致预期、行业景气引擎、未接入的全球行情、Portfolio/DCA浏览器工作台、Research Bridge、OCR资产导入、云业务数据库、账户体系、真实新闻、AI自动摘要、交易模块与全局拖拽布局不在本次范围。既有冻结路线仍有效，设计页不扩张领域合同。[S04](09-source-register.md#s04架构快照)[S05](09-source-register.md#s05功能登记)

## 6. 实施前的差异检查

当前App实际内容优于历史文档中的入口数量表述；新增首页已存在，不能根据旧“6个主入口”删掉首页。底层已实现Local Core不意味着浏览器已完成迁移；这次只触及已存在浏览器研究工作流。若实际发票基线新增业务页，先把它登记为范围Delta并说明是否套用本设计，不在本包中预称已经覆盖未知新页面。
