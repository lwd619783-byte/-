# 交互、路由与响应式合同

## 1. 任务流

入口：首页/行业/个股池/事件 → 快速预览（可选）→ 完整公司研究 → 对应证据或复盘 → 返回原入口。完整研究不是在旧抽屉里继续追加长内容。

保留两类状态：导航状态（页面、公司、标签）与用户浏览上下文（筛选、排序、滚动、所选事件、图表区间）。皮肤变化不进入这两类状态，也不重建业务Store或Provider实例。当前源码以组件状态管理主导航，完整深链是本轮显式交互增量，而不是现有能力声明。[S07](09-source-register.md#s07首页)[S10](09-source-register.md#s10个股池)[S11](09-source-register.md#s11个股详情)

## 2. 轻量可恢复导航（已批准的新增UX合同）

使用现有SPA兼容的hash导航表达主页面、现有stockId、公司标签与必要的行业/事件定位；不要求引入新路由依赖。实现形式由Codex选择最小现有方案，但下列行为固定：

- 只接受白名单页面、标签和当前数据集中的实体ID。不存在/失效ID显示找不到对象及返回入口，不能渲染上一家公司，也不能任意跳外链。
- URL不写入研究正文、导入文件内容、敏感备注或本地存储原文。原根地址仍进入首页，旧入口保留兼容。
- 导航到新页面/实体可进入历史；拖动图表、皮肤切换、开关低频筛选不制造冗长历史。普通筛选保留在当前会话，不新增跨设备持久化。
- 进入公司页前保存原入口的筛选、排序、位置与选中行。浏览器后退/界面返回恢复同一上下文。刷新深链可恢复对象/标签，不承诺恢复未保存表单。
- 切公司时取消或隔离旧请求；成功缓存按身份作用域复用，不因主题切换重置；缓存/准入策略不从UI层重写。

## 3. 状态转换表

| 动作 | 展示结果 | 必须保持 |
|---|---|---|
| 选择另一皮肤 | 外观就地改变 | 页面、字段、筛选、排序、滚动、图表区间、未提交表单 |
| 打开快速预览 | 右侧轻量覆盖层 | 背后列表与数据不变 |
| 关闭预览 | 焦点返回原公司按钮 | 选中行/滚动不跳 |
| 打开完整研究 | 公司完整页与五标签 | 原入口上下文可返回 |
| 切换公司标签 | 只更换内容分区 | 公司身份、关键风险、来源资格 |
| 切换公司 | 新公司完整上下文 | 不保留上一公司读数、错误、未提交操作目标 |
| 编辑元数据 | 小表单并调用既有动作 | 核心假设/历史不被元数据路径覆盖 |
| 开始复盘 | 新复盘记录表单 | 原记录只读、用户明确提交 |
| 确认提醒 | 仅对应任务状态改变 | 不冒充研究完成或买卖信号 |
| 导入失败 | 原始输入与错误明细保留 | 不写业务记录，不自动丢弃失败行 |
| 来源索引失败 | 关闭对应数据提供方输出 | 本地独立快照仍按既有规则可用 |
| 明细部分失败 | 保留成功对象、就地重试失败 | 不重置全站 |
| 存储失败 | 原地错误与恢复/导出入口 | 不显示假保存成功，不清空原始数据 |

## 4. 弹窗与表单

简单操作使用约520–640px弹窗；研究复盘/预期录入约760–900px；复杂导入校验约1040–1200px。具体尺寸随视口自适应，不要求每张表单都满屏。全屏/窄屏表单保持底部主要操作可达。

一个时刻只有一个主模态任务；需要查看资料时用同一流程内的二级内容，不连续叠三层遮罩。键盘焦点进入弹窗、被约束于弹窗，关闭返回触发位置；Escape和显式取消语义一致，但提交中或未保存内容需要明确处理。[W04](09-source-register.md#w04模态对话框模式)

提交中防止重复提交，按钮说明进行中的动作。字段错误贴近字段并提供总览。失败不清空表单。离开有未提交修改的表单时给予丢弃/继续编辑选择；仅切皮肤不能触发离开确认。

删除/覆盖/恢复等危险动作继续使用原合同要求的确认，不能因视觉统一增加“快速跳过”。Watchlist备份/替换与Node Local Core备份/恢复不是同一个产品能力，本次不打通它们。[S04](09-source-register.md#s04架构快照)[S12](09-source-register.md#s12观察清单)

## 5. 搜索与筛选

顶部保留现有搜索作用域，文案显示“当前研究池”，不升级为网络搜索或全站全文引擎。公司/代码等现有检索规则保留。复杂页面第一层只露高频条件，第二层收纳其余条件；激活的隐藏条件在筛选条显示数量与清除入口。

过滤后为空、尚无任何业务数据、权限/来源不支持、加载失败是四种不同状态。清除筛选不能删除记录。默认排序不能因主题或装饰状态变化而改变。

## 6. 响应式矩阵

| 内容宽度 | 全局结构 | 页面行为 |
|---|---|---|
| ≥1440px | 208px主导航、完整顶栏、按任务1–3区 | 公司/验证允许主从；表格固定身份列 |
| 1280–1439px | 主导航可收至72px；仍显示文字提示入口 | 右侧低频栏移到下方；禁止横向压缩正文 |
| 960–1279px | 紧凑导航；主体优先单大区 | 主从详情用抽屉或独立页；宽表仅内部横滚 |
| 640–959px | 导航收纳；顶部筛选可换行 | 两列KPI、图表和表格分段；复盘表单占可用宽度 |
| <640px | 顶栏+底部主要入口/“更多” | 单列、先摘要再正文；主从变列表→详情；触控优先 |

底部入口：首页、行业、个股池、观察、更多；更多包含宏观、验证中心、预期证据，完整导航不丢失。320px最小检查为阅读与控件可达；设计图以390px为窄屏示例。数据表允许自己的二维滚动，页面本身不因宽表溢出。[W01](09-source-register.md#w01wcag-22-文字对比与可读性)

## 7. 各模块窄屏顺序

首页：提醒KPI→今日事项→关注对象→其他事件。宏观：指标读数与时点→来源限制→相关明细。行业：行业选择→驱动/风险→细分→公司。个股池：筛选摘要→公司卡片→完整研究入口。公司：身份/价格/风险→标签→当前章；重要风险不藏到“更多”。观察：待办→所选观察详情→复盘。验证：事件列表→所选事件对照，不左右同时挤压。预期：筛选→来源分组→区间对照→时间审计。

## 8. 无障碍与反馈

关键文字正常字号对比度目标4.5:1，必要图形/控件标识3:1；颜色不作唯一编码；触屏项目目标44px。可见焦点不被霓虹光晕替代；图表也有可读数据入口。系统减少动态效果时停止非必要过渡和背景动画。设计没有不停刷新时钟、价格闪烁、滚动字幕或自动播放装饰。

反馈层级：字段错误就地；局部加载问题靠近模块；跨页面影响的存储/全局索引错误使用稳定状态条；成功提示可短时消失但不能是唯一的已保存证明。屏幕阅读器状态提示不循环朗读每个装饰刷新。
