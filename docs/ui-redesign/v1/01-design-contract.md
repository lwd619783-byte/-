## 1. 已确定的方向与本次决策

主视觉来源是用户选中的《霓虹投研工作台全景.dashboard.png》。保留中文“投研工作台”，不使用后续图片自动产生的 AlphaLens / AlphaVision / AlphaSight 名称。保留青蓝霓虹、深蓝层次、少量紫色与外围空间感；减少正文背后的光效和一层套一层的卡片。

最终策略：**一套产品骨架 + 三套皮肤 + 一次共同的信息架构重构**。A 为深色专业，B 为明亮简洁，C 为霓虹科技且为默认。个股详情、行业、验证等页的新结构供三套皮肤共同使用，不维护三套业务界面。

之前关于原图“70%–80% 属于皮肤”的比例没有测量依据，予以撤回。原始三图只能证明总体模块相似，不能证明图表种类、位置、行数完全相同。本包重新绘制了同一内容的三套主题，并对八类桌面主页面的图元位置、文字、表格顺序、图表坐标做了静态结构指纹对比；见 [checks/theme_geometry.json](checks/theme_geometry.json)。这不是运行时 DOM 或状态保留测试。

## 2. 设计完成的范围

七个一级导航：首页、宏观、行业、个股池、观察清单、验证中心、预期证据。加上公司完整研究视图，共八类核心页面；公司详情不是第八个一级菜单。

交付含八页的三皮肤版本、公司其余四个标签页、行业产业链、个股快速预览、复盘/元数据表单、导入校验、主题选择、组件与异常状态，以及八类页面的窄屏设计。画板索引见 [design/index.json](design/index.json)。所有设计数字和公司均为合成样例，不能用于市场判断或覆盖率承诺。

本包不包含实际交互原型、生产组件或运行时测试。静态图中的控件是设计目标。SVG 是图形设计资产，不是可运行的 React 页面；不提供字体文件。

## 3. 信息组织合同

| 层次 | 默认呈现 | 不得承担的内容 |
|---|---|---|
| 第一层：定位 | 当前对象、关键读数和时点、阻断性限制、主要操作 | 无来源的新结论、未经准入的模型分 |
| 第二层：理解 | 与当前任务有关的趋势、对照、短文、横向比较 | 为了美观生成的趋势、饼图或置信百分比 |
| 第三层：查证 | 原始字段、完整历史、修订、公告、来源和方法 | 不可替代第一层的关键风险提示 |

统一视觉，不强制统一布局。首页以任务与变化组织；宏观以观测与口径组织；行业以比较与下钻组织；个股池以表格组织；详情以章节与标签组织；验证以主从对照组织；预期以来源与时间资格组织。

主要操作在当前页明确。低频管理操作合并到“更多”或专用表单，但不删除。首屏以约 3–5 个信息组为目标，不以缩小字重、字号或隐去风险换取更多卡片。

## 4. 共享骨架与主题边界

同一页面、同一数据、同一视口和密度下，三主题的导航、DOM 语义、模块顺序、筛选、表格列、图表类型、坐标定义、可见记录、状态词与操作权限必须一致。允许颜色、阴影、边界材质、装饰透明度和图表系列色不同。不要用主题条件分支重新计算数据、选择 Provider、改变指标或读写业务记录。

皮肤不是工作区模式。未来“宏观工作区/公司工作区/交易工作区”若要重排模块，须作为独立产品增量，不能塞进本次主题切换。

## 5. 新增交互范围

本次允许设计增量：外观偏好、轻量预览与完整研究分离、五个公司研究标签、详情与筛选返回上下文、合并重复状态说明、低频筛选收纳、窄屏主从切换。路由状态约定见 [04-interaction-and-responsive.md](04-interaction-and-responsive.md)。

不新增自定义布局编辑器、拖拽交易桌面、AI 自动结论、真实交易入口、通知订阅服务、新闻抓取、云同步或账户权限系统。现有状态和业务操作仍交给原服务解释。

## 6. 数据能力边界

本轮读到的当前功能登记和源代码仍将宏观模型、正式牛熊温度、行业景气评分、组合浏览器读模型等区分为合同、未准入或未实现；源码和 Node-only 账本不等于浏览器功能已上线。[S04](09-source-register.md#s04架构快照)[S05](09-source-register.md#s05功能登记)[S08](09-source-register.md#s08宏观)

因此首页以已有事件、观察项、待复盘与核验事项代替原概念图的“市场温度 62”“实时动态”“行业景气分”。宏观当前快照能展示，连续历史只有现有消费者确有可用序列时才启用；当前宏观默认设计明确显示“历史序列尚未接入”。行业数量条是研究池分布，不是假景气分或全行业涨跌热力图。[S08](09-source-register.md#s08宏观)[S09](09-source-register.md#s09行业)

业务事实、时间语义、来源、准入、修订和持久化遵守仓库 `AGENTS.md` 及相关合同，本文件不重新定义它们。界面简化不得回退刚合入的 Master Audit 展示纠偏。[S01](09-source-register.md#s01主干状态)[S02](09-source-register.md#s02永久规则)

## 7. 视觉决定

大面积内容面板安静，霓虹集中于选中态、焦点、主操作和少量趋势线。外围使用可去除的光影或几何装饰，不把背景图片铺在长文、表格或数据标签下。首页不用大幅营销封面挡住研究内容。

正文 14px，常规表格 13px，辅助信息 12px，主标题 24–28px；长文 14–15px / 24–28px 行高。共用字体、字号、行高、圆角、行高与间距，不因“明亮”改成另一套排版。数字对齐采用 tabular 风格，正负号和状态文字与颜色同时存在。
