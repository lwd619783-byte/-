# 全模块页面蓝图

状态：V1.0 APPROVED / FROZEN。配套八页三主题 PNG/SVG 与十张细节/流程图，见 [design/index.json](design/index.json)。此处未画在首屏的内容，不等于被删除；完整迁移表见 05。

## P01 首页｜今天先研究什么

首屏：页面标题与一句定位；四个现有统计（待复盘公司、本周研究事件、正在观察、数据核验项）；左中优先任务与所选对象价格脉络；右侧最近研究事件；下方关注公司与提醒入口。使用短头部而非原有近一屏的大封面。现有 HomePage 的封面、模块入口和统计属于迁移对象。[S07](09-source-register.md#s07首页)

“最近研究事件”只消费当前已有 ResearchEvent 等信息，不请求新的新闻服务。“今天先处理什么”排序复用现有任务优先级、到期和逾期逻辑，不新建推荐算法；按服务返回可用项目生成，无项目时显示空状态。首次访问没有用户清单时，不把演示模板当成用户观察。

主操作：进入具体复盘/证据；点击公司进入快速预览或完整研究；所有六个研究入口保留在导航中。价格脉络必须绑定一个真实可用研究对象及其时点，不能从多个涨跌数合成指数。

验收场景：用户可以在首屏找到未完成研究；无历史价格时图表区域解释缺失，其他任务不受影响；统计口径和实际清单一致；首页不出现未经准入的市场温度。

## P02 宏观｜哪些观测可确认

首屏：分类导航（增长与价格、流动性、政策与利率、信用与社融及其余既有分类）；所选指标的观测值、单位、观察期；来源时点与当前资格；下方完整明细。现有九类分类与原始字段查询保留，不以五个可见页签删减分类。[S08](09-source-register.md#s08宏观)

当前默认是快照设计：没有已接入历史就不用趋势线填空。缺历史时用稳定的“历史序列尚未接入当前页面”信息区，保留来源查询。未来在现有合同和读取路径支持连续序列后，同一位置可切换为历史趋势；这种能力启用不是本票自动授权的 Provider 接入。

原始值和数据状态分开；“时效待核验”不能变成“过期”或“实时”，文件生成时间不是全部指标的发布时点。数值覆盖仅表示条目有值，既有重复指标和分母规则照常解释，不变成宏观强弱或信心分。

主操作：选分类、选指标、展开来源口径、查看原始字段。空分类在收纳入口中保留“待接入”标记。原始长 URL 放详细层，不在每个摘要中重复。

验收：单个快照、月度指标、只有日期、发布时间缺失、未来异常时点、空分类分别可读；模型未准入时不出现方向判断。

## P03 行业｜先比较，再下钻

桌面左侧是行业选择，中间是“研究概览 / 细分比较 / 产业链”。概览集中展示核心驱动、风险、催化与资料时点；比较使用代表公司表格、研究池数量分布和可用数据，不把静态景气文字转换为量化评分。[S09](09-source-register.md#s09行业)

行业资料的“景气 / 阶段 / 驱动 / 催化 / 风险 / 风格”都保留。资料来源或更新时间未知时明确标注，不自动冒充用户判断或官方事实。数量条的统计对象写成研究池公司；分母/是否重复必须与原列表一致。

细分比较：需求、供给格局、竞争壁垒、价格/订单/产能趋势、未来关键变量；原有行情摘要、比较表和公司卡片可在子视图切换。产业链独立显示上中下游关系，不声称收入占比。机器人保留全部环节、核心/观察池区分和未上市公司线索。未上市对象不能进入行情合并与可交易资产排名。

主操作：行业选择→细分选择→代表公司→公司研究；从公司返回保持行业/细分和滚动。窄屏把行业选择收成可搜索的选择器，不生成第二根常驻侧栏。

验收：机器人“全部”和其他行业默认细分逻辑不丢；搜索仍限定原有范围；私营公司仍是线索；缺乏同口径市场涨跌时不造热力图。

## P04 个股池｜筛选效率与上下文

桌面默认研究表格，保留表格/卡片切换。首层保留行业、细分、市场、数据质量、排序；池内搜索、风险、其余既有选项进入“更多筛选”，展开后全部可达。选项语义不变，尤其“行情采集24小时内”不等于交易价格是24小时内的报价。[S10](09-source-register.md#s10个股池)

表格关键列：公司（连同代码）、市场、价格及币种/时点、涨跌、明确口径估值、数据状态、风险、操作。额外字段收成列详情或卡片全文，不删除核心看点、市值、覆盖、缺失等。数字列右对齐；缺值用破折号并可查原因，不因排序被变成0。

快速预览：仅公司、价格和时点、核心限制、已有价格线、研究摘要、主要操作。桌面右侧覆盖层，不为塞入所有财务形成第二个长详情。关闭返回原选中行；“打开完整研究”进入公司页。

验收：所有现有筛选/排序/卡片行为保留；相关市场选项不能因没有可靠数据而显示假记录；从详情返回保持筛选、排序、滚动；切皮肤时不重新查询或清空条件。

## P05 个股详情｜完整研究页

共用固定身份与摘要：公司、代码/市场、价格快照及其时间语义、风险与数据限制、添加观察/开始复盘等原有操作。滚动后摘要可压缩但不遮挡锚点；长公司名允许换行，不能只在 hover 才知道身份。主内容五个标签共用一套组件结构。[S11](09-source-register.md#s11个股详情)

| 标签 | 默认内容 | 详细层去向 |
|---|---|---|
| 研究概览 | 如何赚钱、当前研究依据、反对证据、下一步验证；价格小图 | 宏观行业背景、已有投资逻辑全文、关联公司、产业链、主题标签 |
| 经营与财务 | 可用年度/分期趋势、关键财务质量、缺失说明 | 三表完整历史、主营业务拆解、F10、公司资料原始口径 |
| 价格与估值 | 已有收盘价序列、估值快照、口径/币种 | 八项行情数据、信号雷达、行业概念/地区标签；估值历史无数据就不显示 |
| 预期与验证 | 单一来源类别的预测与实际、可比性、事前资格 | 业绩验证链、预期快照、修订/纠错、时间审计与排除理由 |
| 证据与复盘 | 公告/研究事件/复盘历史，主要研究动作 | 研报、完整公告、来源详情、数据质量、元数据编辑、归档恢复与修正 |

来源、状态、重要限制就地呈现；完整技术 provenance 可展开。摘要仅重排已有字段，不自动生成新的AI结论。研究概览“支持/反对”的归类没有已有依据时，不由 UI 私自推断；显示原有章节及其来源即可。

行情、财务、公告加载仍按公司与身份隔离；异步响应不能污染下一家公司；预期全局索引资格不能因新页签隐藏而绕过。打开价格标签不触发全市场明细预取。

验收：原长抽屉每个区块和回调均有去向；五个标签真实可达；当前公司变更与迟到响应隔离；只读官方证据无编辑；焦点返回与浏览器返回一致。

## P06 观察清单｜提醒与判断不混淆

首屏优先列表而非展开所有研究长卡片。默认保留个人观察清单，提供仅逾期/新事件/归档等视图以及完整原筛选。选中项在侧栏/窄屏详情展示关注理由、投资假设、验证条件、风险条件、事件、复盘时间与历史。[S12](09-source-register.md#s12观察清单)

主操作保留添加观察、编辑元数据、开始复盘、纠错、归档、恢复、确认提醒、暂缓7天、忽略、模板载入、备份/导入。确认提醒只是对应任务状态，不冒充“复盘完成”。投资假设变更走复盘，不偷换为元数据编辑。

示例模板默认收起，单独标明不计入用户数据；只有用户主动载入才按原服务生成记录。损坏存储提示和原始内容导出入口保留；不借主题设置覆写、迁移或清空 LocalStorage 业务空间。

验收：原筛选六类与开关、五类排序可达；归档仍可恢复；保留append-only复盘；每个按钮仍调用同一个业务意图。

## P07 验证中心｜选中事件的对账

主从结构：筛选→事件列表→选中事件的事前证据/事后事实/比较条件。另有“全局核验队列”和“业绩验证链”子视图，不把它们的筛选作用域暗中改成与事件列表完全一致。[S13](09-source-register.md#s13验证中心)

关键条件分别显示：来源核验、事前时间资格、数值可比性。缺事前证据、字段不可比、来源冲突、仅元数据、报告期未匹配等原因均保留，不能合并成一个红色失败状态。已有服务没有正式比较结果时，只显示阶段数据，不在UI重算结论。

主操作：查看公司、关联观察项后开始复盘、打开原始公告、查看链条详情。官方指引事件保留只读来源。链条缺少阶段只表示当前资料未见，不能指责公司违规披露。

验收：数据模式变化或索引失败时事件与任务传播仍符合原服务；新UI不能自己解锁比较；无选中对象时给明确空状态而非展示上一家公司。

## P08 预期证据｜来源、时间与数值对齐

主视图为同公司/报告期/指标的来源对照与修订时间线；公司指引、单家机构、机构一致预期、用户预测分别可辨。四个子入口：有效快照、业务修订、数据纠错、导入记录。全部既有筛选保留在基础/高级两层，不减少维度。[S14](09-source-register.md#s14预期证据)

Provider 索引状态与公司明细状态分开；索引失败时数据提供方全局关闭，本地快照仍可使用；仅明细失败时不抹掉成功公司。重复/元数据差异、内容冲突、排除/警告都可见。正常摘要压缩，影响比较的冲突默认展开。

公司官方记录只读。本地独立快照仍可新增与修正，修订和纠错不可混写。时间线有同日、相同精确时点或不确定业务顺序时使用“并列/不确定”显示，不能按导入顺序强行排序。

主操作：新增、纠错、导入、导出、时间审计、查看原始来源、打开公司。没有可靠机构一致预期时，不用多条零散预测制造“共识”。

验收：官方与本地重复不双计；冲突仍阻断比较；区间、点值、舍入容差由现有引擎判断；事后记录不进入事前比较。

## 共用低频页面与流程

主题菜单、快速预览、元数据编辑、复盘、预期新增/纠错、导入/导出、备份/恢复、来源详情、完整表格、原始JSON/CSV预览共享同一套尺寸和状态语言。画板展示其中代表状态；未单独绘制的每一张表单按04的状态表和05的操作映射实现，不能因缺少单独PNG删减字段。

超出当前域的 Portfolio、DCA 浏览器管理、正式 Market Regime、Research Bridge、自动新闻与AI总结仍为后续任务，不伪装成空菜单已上线。
