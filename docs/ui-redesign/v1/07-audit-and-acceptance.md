# 终局综合审计与验收清单

设计检查与实现检查分开。当前可报告的是画板生成、图号/结构指纹、定义色对和文件交付；以下运行时检查在Codex实现前统一为NOT_RUN，不能自动写PASS。

## 1. 审计证据格式

每项记录：ID、预期、实际、证据文件/测试名、输入base SHA、HEAD SHA、结论PASS/FAIL/NOT_RUN、影响范围。截图标明模式、fixture、时点、主题、视口。不要用“肉眼没问题”替代来源/持久化测试。

## 2. 主题与视觉

| ID | 检查 | 通过标准 |
|---|---|---|
| T01 | 默认与恢复 | 首次C；有效保存值优先；非法值回C |
| T02 | 主题独立性 | 外观与数据模式无互相改动 |
| T03 | 业务数据 | 主题切换前后业务导出/Store内容一致 |
| T04 | 上下文 | 筛选、排序、选中公司/事件、图表区间与滚动不变 |
| T05 | 表单 | 未提交字段不丢，主题切换不当作离开表单 |
| T06 | 几何 | 同视口同内容三主题布局、图型、列位、记录順序一致 |
| T07 | 系列语义 | 图例与正负方向不随皮肤倒置 |
| T08 | 存储异常 | 外观写入失败不触碰业务键，不阻塞操作 |
| T09 | 文字对比 | 真实背景/透明层正常文本目标4.5:1 |
| T10 | 控件与图形 | 必要标识目标3:1，焦点可见，状态非纯色 |
| T11 | 字体与中文 | 长名/混排/大数值不裁断，不靠hover读核心信息 |
| T12 | 装饰边界 | 不遮挡正文，不影响命中区域或制造行情更新错觉 |

## 4. 数据语义、来源与业务

| ID | 检查 | 通过标准 |
|---|---|---|
| D01 | 真实缺值 | 不补0，不从设计样例回填真实模式 |
| D02 | 宏观时点 | 观察期/生成/发布等原语义不混同 |
| D03 | 宏观模型 | 无准入不显示方向分/牛熊温度/假历史 |
| D04 | 行业比较 | 研究池数量不伪装为景气或全市场统计 |
| D05 | 财务口径 | 单季/累计/年度、币种/单位不混比 |
| D06 | 价格图 | 无OHLC不画K线；缺口不断言连续 |
| D07 | 预期来源 | 公司/单机构/共识/用户区分，不造假共识 |
| D08 | 资格三分 | 来源核验/事前有效/数值可比性分别传播 |
| D09 | 原时间精度 | 同日/相等/顺序不确定不按UI顺序硬排 |
| D10 | 重复与冲突 | 重复不双计；内容冲突仍排除比较 |
| D11 | 索引关闭 | 官方全局失败不漏入公司/事件/任务分支 |
| D12 | 局部失败 | 明细局部失败不丢成功对象或本地快照 |
| D13 | 官方只读 | 无可编辑、删除或替换官方记录入口 |
| D14 | 观察动作 | 确认提醒不等于复盘；元数据不覆写假设 |
| D15 | 历史 | 复盘/修正/业务修订关系与append-only保留 |
| D16 | 导入 | validator判定与写入语义不变；失败保留输入 |
| D17 | 恢复 | 原备份/替换/重置确认与原始内容导出不丢 |
| D18 | 未上市对象 | 不进入可交易行情统计/排名 |
| D19 | 风险可见 | 阻断性原因在相关摘要默认可见 |
| D20 | 覆盖口径 | 分母/去重/消费者状态不因为缩短文字被重定义 |

## 5. 工程、性能与发布

| ID | 检查 | 通过标准 |
|---|---|---|
| E01 | 栈不漂移 | 无未经批准的新UI框架/图表库/大版本升级 |
| E02 | 浏览器边界 | 不导入Node-only Local Core、数据库或raw SQL |
| E03 | 重数据 | 保留summary→manifest→公司明细lazy路径 |
| E04 | 首屏 | 不一次预取全公司历史，不将演示PNG塞入业务bundle |
| E05 | 门禁 | 仓库适用test/build/ui:audit/data:audit等真实运行；不降阈值 |
| E06 | 性能证据 | 相同环境/fixture记录前后bundle、首屏加载与交互；结果不凭想象 |
| E07 | Git证据 | base/HEAD/远端差异可复现，工作树与其他worktree变化如实报 |
| E08 | 发布边界 | 只普通push；独立审查通过前不PR/merge/deploy |

## 6. 最小截图矩阵

桌面1440或1600宽：八页×三皮肤，共24张，固定fixture、时间与内容；不得只测C。窄屏390宽：八页C共8张；关键复盘/导入与公司页还要在A/B中检查。另做320px溢出、200%缩放和reduced-motion检查，不要求每个状态重复生成无意义的全组合截图。

异常夹具至少覆盖：无用户观察、无价格历史、仅宏观快照、未知时点、港股财务未接入、单公司明细失败、官方索引全局失败、本地与官方冲突、并列时间、损坏存储、导入阻断、非常长公司名、负值与大数值。夹具明确synthetic，与真实数据隔离。

## 7. 关键回归序列

A. 个股池筛选→滚动→预览A→完整研究→财务→切三主题→后退。验证筛选、位置、公司、标签、数据与请求未异常重置。

B. 填写复盘一半→切主题→取消离开→继续编辑→提交一次。验证内容保留、无重复记录、历史追加而非覆盖。

C. 官方索引成功→注入校验失败→切页/主题→本地预期仍显示。验证官方记录在所有消费者被关闭，局部漂亮UI不能漏出失效数据。

D. 官方/本地相同证据内容冲突→查看时间审计→切主题→导出。验证冲突可见、比较排除、原始本地记录仍在。

E. 真缺值/仅一个快照→切主题/日期范围→导出。验证无补0、无假线、无新机构共识。

## 8. 问题分级与最终放行

阻断：业务记录损坏、来源/时间/准入回退、错误比较结论、不可恢复的数据丢失、核心操作不可达。高优先：跨公司串数、主题导致表单/筛选丢失、重要警告隐藏、窄屏无法完成任务。一般：不影响识别的装饰偏差或间距微调。

最终审计报告必须分别给出：设计一致性、业务回归、数据与时间语义、持久化、访问/响应式、工程门禁与未执行项。不以“截图漂亮”或“测试数量很多”替代这些结论。阻断未清零不得建议合并。
